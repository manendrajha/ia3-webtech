# Blood Donor Management System

A simple and responsive Blood Donor Management System built using React JS and Bootstrap as part of our Web Technology project.

## Features

- Add new donors
- View all registered donors
- Search donors by blood group
- Update donor details and availability
- Delete donor records

## Tech Stack

- React JS
- Vite
- Bootstrap 5
- JavaScript
- CSS

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/ia3-webtech-frontend.git
```

**2. Navigate to the project folder**

```bash
cd ia3-webtech-frontend
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the application**

```bash
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173/`).

## Note

This is currently a frontend prototype. Donor records are stored in browser local storage. Backend and database integration will be added later.
